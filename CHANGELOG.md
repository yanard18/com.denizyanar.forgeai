# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-07-31

### Added

-   **Initial Release of ForgeAI**.
-   **ReAct Engine**: Core reasoning loop for processing prompts.
-   **Conversational UI**: ForgeAI Assistant window for interacting with the agent.
-   **Tooling System**: Initial set of tools for file management and content editing (`ListFiles`, `MoveAsset`, `DeleteAsset`, `ReadFile`, `WriteFile`, `ReplaceText`).
-   **LLM Providers**: Support for OpenAI and Gemini models.
-   **Configuration**: Settings panel in Unity's Preferences to manage API keys and model selection.
-   **Approval System**: Safety mechanism requiring user approval for file modifications.
